# 용어 사전

| 한글명 | 영문명 | 설명 |
| --- | --- | --- |
| 회원 | Member | 서비스에 가입한 사용자. 이메일, 비밀번호, 포인트를 가지며 카카오로 로그인하면 카카오 액세스 토큰도 가진다. 카카오 응답의 user/account도 회원을 가리킨다. |
| 관리자 | Admin | 관리자 화면(`/admin/*`)에서 상품과 회원을 추가, 수정, 삭제하고 회원 포인트를 충전하는 사람. |
| 상품 | Product | 회원이 위시에 담거나 주문할 수 있는 판매 대상. 이름, 가격, 이미지 URL을 가진다. |
| 카테고리 | Category | 상품을 묶는 분류. 전자기기, 패션, 식품 |
| 옵션 | Option | 상품의 세부 선택지. 상품마다 최소 1개가 있어야 하며, 옵션별로 재고를 가진다. 주문은 옵션 단위로 한다. |
| 위시 | Wish | 회원이 관심 있는 상품을 담아 둔 항목. 같은 상품은 한 번만 담긴다. |
| 주문 | Order | 회원이 옵션을 골라 주문 수량만큼 포인트로 구매한 기록. 선물 메시지를 남길 수 있다. |
| 상품명 | Product.name | 상품을 표시하는 이름. 최대 15자이며, "카카오"는 담당 MD와 협의한 경우에만 쓸 수 있다. |
| 옵션명 | Option.name | 한 상품 안에서 옵션을 구분하는 이름. 최대 50자이며 같은 상품 안에서 중복될 수 없다. |
| 단가 | price | 상품 1개의 가격. |
| 주문 금액 | totalPrice | 단가 × 주문 수량. 주문할 때 회원 포인트에서 이만큼 차감된다. |
| 재고 | stock | 옵션별로 남아 있는 판매 가능 수량. 주문하면 주문 수량만큼 줄어든다. |
| 주문 수량 | quantity | 한 번의 주문에서 구매하는 옵션 개수. 1 이상이어야 한다. |
| 포인트 | point | 회원이 주문 금액을 결제하는 데 쓰는 잔액. 관리자가 충전한다. |
| 충전 | charge | 관리자가 회원 포인트를 늘리는 동작. 충전 금액은 1 이상이어야 한다. |
| 차감 | deduct | 주문할 때 재고나 포인트를 주문만큼 줄이는 동작. 남은 양보다 많이 차감할 수 없다. |
| 받는 사람 | receiver | 주문한 선물을 받는 회원. 주문할 때 회원 ID(`receiverId`)로 지정하며, 카카오 메시지를 받는다. |
| 선물 메시지 | message | 주문자가 주문할 때 남기는 메시지. 선택 사항이며, 카카오 메시지 본문에 함께 담긴다. |
| 카카오 메시지 | kakaoMessage | 주문 후 카카오톡 "나에게 보내기"로 보내는 알림. 카카오 로그인 회원에게만 보내며, 발송에 실패해도 주문은 유지된다. |
| 회원 가입 | register | 새 회원을 만드는 일. 이메일 가입, 카카오 첫 로그인 시 자동 가입, 관리자 추가가 모두 해당한다. |
| 인증 | auth | 로그인부터 토큰 발급까지의 흐름 전체. 이메일·비밀번호 로그인과 카카오 로그인이 있다. |
| 인증 확인 | auth check | 요청의 Authorization 헤더에 담긴 토큰으로 회원을 찾는 단계. 찾지 못하면 401로 응답한다. |
| 토큰 | token | 서비스가 발급하는 JWT. 회원 이메일을 담고 있으며 로그인과 회원 가입 시 발급된다. |
| 카카오 액세스 토큰 | kakaoAccessToken | 카카오 로그인 시 카카오에서 받은 토큰. 카카오 메시지를 보낼 때 사용한다. 서비스 토큰과 구분하기 위해 항상 kakao 접두어를 붙인다. |
